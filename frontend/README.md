# Клиентская часть панели

Панель сохраняет серверные маршруты и формы Django. React добавляет интерактивные графики на страницу статистики; вход и операции с заявками работают без JavaScript. При недоступности API показана ошибка с повторной загрузкой, при отсутствии данных — пустое состояние. Общая статистика по статусам и категориям остаётся в серверной разметке. Для графиков доступна раскрываемая таблица с полными именами и значениями.

## Сборка

Требуются Node.js 22.12+ и pnpm 11:

```powershell
cd frontend
pnpm install --frozen-lockfile
pnpm build
```

Результат: `app/web/static/web/dist/panel.js` и `panel.css`. Эти файлы публикуются вместе с Python-приложением. Node.js на сервере не нужен. Фиксированные имена позволяют подключать сборку напрямую из Django; WhiteNoise обслуживает их после collectstatic.

## Компоненты

Графики Bklit установлены официальной командой `pnpm dlx shadcn@latest add @bklit/area-chart @bklit/bar-chart @bklit/y-axis`. Их исходники находятся в `src/components/charts`, лицензия — `LICENSE-BKLIT`; `patterns/LICENSE-visx-pattern` сохраняет уведомление об исходном коде паттернов. Примитивы Card, Button, Tabs, Skeleton установлены из официального registry shadcn. Импорт `cn` у примитивов направлен на общий локальный helper. Документация: https://bklit.com/docs/installation, https://ui.shadcn.com/docs.

Lucide React используется в графиках и для генерации серверных SVG. После изменения набора иконок выполните `node scripts/generate-icons.mjs`; результат уже сохранён в шаблоне, CDN и клиентский JavaScript для иконок не требуются. Лицензия — `LICENSE-LUCIDE`.

Anime.js выполняет короткое появление заголовка/формы и сообщений. Motion for React анимирует раздел графиков и управляет reduced-motion. При `prefers-reduced-motion` отключены появления, анимации серий и подсветки графиков; у всплывающих подсказок отключены перемещения и изменение размера. Все данные загружаются только с собственного `/api/statistics/`, состояние и пароли не сохраняются в браузерное хранилище.
