# Обновление оформления

Пользователь задал направление: Neumorphism + Glassmorphism, мобильная адаптация всей панели, HTML и Premium-эмодзи в боте, цветные кнопки, референсы @pure_cobot, @PUREOTRAB_BOT, @pure_tebot, @purebuy_bot.

## Веб

Светлая серо-мятная основа, тёмный контрастный текст, бирюзовый акцент. Мягкие парные тени у объёмных элементов, полупрозрачные поверхности и тонкая светлая кромка у стеклянных панелей. Размытие применяется к ограниченным поверхностям, без непрерывной фоновой анимации. Системный шрифт с поддержкой кириллицы, ясная иерархия, табличные цифры.

Обновляются вход, лента, фильтры, карточка, история, действия, статистика, ошибки и оформление админ-панели. Функции ТЗ, маршруты и серверная авторизация сохраняются. Новые показатели отображаются только по реальным данным.

На узких экранах навигация компактная, таблица заявок становится карточками, формы и колонки складываются последовательно. Сенсорные цели не меньше 44 px, поля минимум 16 px. Проверка ширин 320, 375, 390, 768, 1024, 1440 px: нет горизонтального переполнения, элементы доступны с клавиатуры, длинные тексты переносятся.

Учитываются видимый focus-visible, skip link, названия полей, ошибки с исправлением, reduced motion, масштабирование, safe-area, запасной непрозрачный фон без backdrop-filter. Основание проверки: официальный скилл Vercel web-design-guidelines и актуальные Web Interface Guidelines.

## Бот

Короткие HTML-сообщения с заголовками, цитатами, номером заявки в code и индикатором этапа. Пользовательский текст и названия справочника экранируются. Длинные сообщения делятся без разрушения HTML и с учётом Unicode.

Служебные кнопки получают семантический стиль primary/success/danger по Telegram Bot API; текст произвольного цвета API не поддерживает. Premium-эмодзи подключаются только с реальными идентификаторами и с возможностью вернуться к обычным эмодзи при недоступности. Чужие сообщения и изображения не копируются.

Inline-кнопки используют идентификатор категории и ключ черновика вместо текста как команды. Устаревшие и чужие нажатия не меняют другой черновик. Ввод текстовых команд и сохранённые черновики остаются совместимы. Подтверждение не дублирует заявку. Старые уведомления в очереди продолжают доставляться; преобразование в HTML выполняется на границе транспорта.

В качестве визуального референса пользователь предоставил archive-2026-11-05T113108+0100.tar.gz. Прочитаны только app/emoji.py, app/ui.py, app/handlers/start.py и app/bot.py. Заимствованы семантические стили inline-кнопок, HTML-структура, идентификаторы иконок и идея последовательного fallback. Идентификаторы двенадцати эмодзи проверены read-only методом getCustomEmojiStickers. Архив, исполняемые файлы, настройки и бизнес-логика референса в проект не переносятся.

Пользователь запретил дальнейшее управление компьютером; интерактивная браузерная проверка в этой итерации не выполняется. Проверка веба ограничивается кодом адаптивных правил, серверным HTML и автотестами; это ограничение указывается в отчёте.

## Проверка отказов

- Слишком слабый контраст мягких теней: интерактивность дополнительно обозначается границами, текстом и focus-ring.
- Telegram отклоняет недоступные custom emoji: повтор без custom emoji, без потери сообщения и клавиатуры.
- HTML разрезан посередине тега либо пользователь ввёл разметку: структурное разбиение и тесты предельного ввода, экранирование пользовательских данных.
