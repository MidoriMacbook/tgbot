# Производительность

Фактический замер 5 ноября 2026 года, 11:51 МСК. Машиночитаемый результат: [performance.json](performance.json). Скрипт [benchmark.py](../../scripts/benchmark.py) создаёт отдельную SQLite, применяет миграции, поднимает временный Django HTTP-сервер и завершает его после измерения. Рабочая БД и Telegram не используются.

Используется фактическое неокруглённое время таймера; поэтому ручной расчёт по округлённому времени может немного отличаться. Этот результат — краткий локальный автоматизированный прогон, а не длительное испытание насыщения и не обещание обработки такого числа реальных обращений людьми. Одновременно шли проверки разработки; точная задержка при повторе изменится.

## Что считается циклом

1. Семь шагов реального сохраняемого диалога: /start → подача → группа → элемент → описание → контакт → подтверждение.
2. Проверка созданной заявки в общей БД и номера в ответе бота.
3. Настоящие HTTP-запросы с cookies и CSRF: лента, карточка, взятие, переназначение другому сотруднику и закрытие с результатом. Каждый POST проходит Django middleware, формы и общий сервис, ответ включает карточку после redirect.
4. Обработка двух настоящих заданий очереди инъецированным локальным транспортом; ожидание подтверждения доставки своей заявки при параллельных обработчиках.
5. Проверка окончательного статуса, четырёх записей истории, двух доставленных заданий и ответа владельцу.

Скорость одного SQL-запроса здесь не используется. Вход сотрудников, подготовка исходной БД и прогрев выполняются до таймера. Общая длительность измеряется настенными часами; задержка отдельного цикла включает ожидание блокировок, HTTP и локальную доставку.

Ввод человеком, реальная работа исполнителя и сеть Telegram API не измерялись. Ответы Telegram заменяет только транспорт: логика бота, общая БД, веб-обработка, история, очередь, аренда и подтверждение доставки работают. Следовательно, минутный срок реального сообщения этим результатом **не подтверждается**. Его отдельная проверка с настоящим Telegram приведена в [живом сценарии](scenario.md).

## Повторение

```powershell
.venv/Scripts/python.exe scripts/benchmark.py --cycles 100 --users 4 --dataset 250 --warmup 5
```

Порт 8765 должен быть свободен. Для другого порта используйте `--port 8767`. Для сохранения отдельного отчёта: `--output artifacts/повтор.json`. БД и логи каждого прогона остаются в игнорируемом каталоге artifacts. Скрипт не очищает рабочие данные и не выводит созданные временные пароли.
