# Проверка обновления оформления

Дата: 5 ноября 2026 года. План: [soft-glass](plans/2026-11-05-soft-glass.md).

## Объём

Обновлены вход, оболочка сотрудников, лента и фильтры, карточка и история, действия, статистика, ошибки и оформление админ-панели. Серверные маршруты, роли и бизнес-правила сохранены. Внешние шрифты, CDN и новые зависимости не добавлялись.

Применён официальный скилл Vercel [web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) и его [актуальные правила](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md). Проверены подписи полей, семантические ссылки и кнопки, имена иконок, фокус, skip link, состояния ошибок, перенос длинного текста, параметры фильтров в URL и reduced-motion. Из полей входа убран autofocus, сохранена поддержка менеджеров паролей.

## Адаптивные правила

Это проверка исходников CSS и серверного HTML, а не результат измерения страницы в браузере.

| Ширина | Предусмотренное поведение |
| --- | --- |
| 320 px | Фильтры в одну колонку, компактная навигация, уменьшенная декоративная композиция входа |
| 375–390 px | Лента карточками, вход и карточка обращения в одну колонку, фильтры в две колонки с полным полем исполнителя |
| 768 px | Лента карточками, сведения и действия последовательно; фильтры в три колонки |
| 1024 px | Горизонтальная оболочка, табличная лента, две колонки карточки |
| 1440 px | Боковая навигация, полноценная таблица и боковая панель действий |

У полей заданы min-width:0 и max-width:100%, текст переносится, основные сенсорные цели имеют высоту 44–48 px. Для браузеров без backdrop-filter предусмотрены непрозрачные поверхности. На телефонах админские формы складываются, а широкие таблицы прокручиваются внутри контейнера результатов. Учитываются safe-area и запрет лишнего движения.

Расчёт контраста токенов: вторичный текст #52655e на наиболее тёмном мятном фоне #d4e8db — 4,84:1; границы полей — 3,24–3,26:1; белый текст основной кнопки — 5,00:1; четыре статусные метки — не менее 5,10:1. Эти расчёты не заменяют полный аудит каждого отрисованного состояния.

## Бот и референс

По просьбе пользователя прочитаны модули оформления предоставленного архива. Использованы inline-кнопки с ID выбора, HTML-структура, цветовые стили и идентификаторы Premium-эмодзи. Архив и его настройки в репозиторий не добавлялись. Двенадцать идентификаторов проверены методом getCustomEmojiStickers без отправки сообщений.

Добавлены проверки экранирования пользовательского HTML, корректных длинных Unicode-сообщений, сохранения действий при недоступности Premium, выбора категорий с зарезервированными названиями, чужих и устаревших кнопок, а также повторного подтверждения. При независимом ревью обнаружено и исправлено устаревшее подтверждение после изменения контакта: кнопки теперь привязаны к показанному варианту данных. Исправление отдельно перепроверено.

Исторический живой прогон из `docs/demo/telegram-live.json` относится к предыдущему оформлению.
