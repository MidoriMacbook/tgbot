# Итог доработки для размещения

Подготовлены `pur3.me`, узел `c-pl-2.apexnodes.xyz` и порт `10064`. Настройки и секреты находятся в локальном `.env`; в репозитории публикуется только `.env.example`. DNS и удалённый Pterodactyl не изменялись.

Один `run.py` выполняет подготовку и контролирует сайт, бота и уведомления. Веб обслуживается Waitress/WhiteNoise; на хостинге достаточно Python и готовых клиентских assets.

Бот редактирует ответы на inline-кнопки, показывает постоянное нижнее меню с разными цветами и иконками. Цвета, эмодзи, подписи, тексты и таймауты задаются в env. При недоступном Premium сохраняется резервная отправка; если редактирование невозможно, отправляется новый ответ. Ввод описания/контакта и отдельные уведомления по-прежнему могут создавать сообщения.

Главный оператор задаётся CHIEF_OPERATOR_USERNAME, начальный пароль — CHIEF_OPERATOR_PASSWORD. В `/team/` ему доступна генерация операторских и администраторских учётных записей с однократным показом пароля. Его аккаунт защищён от изменения другими администраторами. Существующий пароль не сбрасывается при запуске.

Тёмная адаптивная панель использует реальные Lucide, shadcn, Anime.js, Motion for React и компоненты Bklit из официального registry. Графики показывают поступления и закрытия по дням, результаты сотрудников; период 7/30/90 дней. Счёт закрытий ведётся по автору события, не по текущему назначению. Доступны ошибки загрузки, пустое состояние, повтор и таблица значений.

Выполнена одна итоговая серия проверок: 71 тест OK, Django check без замечаний, изменений миграций нет, pip check без конфликтов. Клиентская TypeScript/Vite сборка успешна. Vite предупреждает о JS-файле больше 500 kB: текущий bundle около 654 kB, gzip около 215 kB. Это не ошибка сборки. Интерактивная браузерная проверка не выполнялась по указанию пользователя; реальное размещение и открытие Telegram Mini App после DNS ещё не проверены.

TLS в контейнере не требуется при внешнем HTTPS-прокси. Для выбранного варианта Cloudflare нужен Origin Rule на порт 10064; одной DNS-записи недостаточно. Точные записи и границы HTTP origin описаны в [инструкции](hosting.md).

Локальный единый launcher запущен: вход и готовый panel.js вернули HTTP 200, тёмная тема присутствует в HTML. Перед запуском того же бота на хостинге остановите локальный run.py, чтобы не было двух polling-процессов с одним токеном.
