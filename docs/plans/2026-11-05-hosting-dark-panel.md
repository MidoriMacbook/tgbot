# Размещение и тёмная панель

Запрос пользователя: единый запуск Python для Pterodactyl, конфигурация бота в .env, редактирование одного сообщения, нижнее меню с цветами и иконками, главный оператор с выдачей админских доступов, тёмный Refero/Shadcn интерфейс, Anime.js, Motion for React, статистические графики Bklit.

## Решения

Django сохраняет авторизацию и бизнес-правила. React используется в интерактивных разделах и собирается локально в статику Django; на хостинге Node не нужен. Графики — реальные компоненты Bklit из официального shadcn registry; иконки — Lucide. Анимация уважает reduced-motion. Новые зависимости фиксируются lock-файлами.

Один run.py запускает и контролирует сайт, polling бота и уведомления в одном контейнере. HTTP слушает 0.0.0.0:10064; внешний адрес c-pl-2.apexnodes.xyz:10064. Публичный домен pur3.me. Telegram Mini App требует внешний HTTPS; сертификат обслуживает внешний прокси, а контейнер остаётся HTTP. Подготовлена схема Cloudflare Flexible и Origin Rule на порт 10064.

Критичные конфигурационные значения и визуальные настройки бота читаются из .env. Секреты не публикуются. Главный оператор задаётся CHIEF_OPERATOR_USERNAME, bootstrap-пароль — CHIEF_OPERATOR_PASSWORD; существующий пароль не сбрасывается при каждом запуске.

## Работы

- [x] Сервер: env/config, единый launcher, production WSGI/static, Pterodactyl-настройки, главный оператор, выдача доступов, API статистики.
- [x] Веб: тёмная адаптивная оболочка, Lucide, shadcn-компоненты, React/Bklit-графики тренда и закрытий по сотрудникам, Anime.js/Motion, управление доступом.
- [x] Бот: конфигурация env, разные emoji/цвета, нижнее меню, edit вместо нового сообщения, Mini App-кнопка при настроенном HTTPS URL.
- [x] Интеграция: итоговая сборка и значимые проверки, запуск, документация DNS/прокси; результат подготовлен к публикации в prototype и синхронизации Desktop.

Управление компьютером по-прежнему запрещено пользователем. Проверки не запускаются после каждого этапа; выполняется итоговая проверка.

## Контракт интерфейсов

GET /api/statistics/?days=30 (администратор): summary, trend=[{date,created,closed}], operators=[{name,completed,rejected,total}], categories=[{name,total}]. Даты в Europe/Moscow, закрытия считаются по событиям закрытия и их авторам, а не текущим назначениям.

/team/ и POST /team/generate/ доступны только главному оператору. Форма generation_form принимает username (необязательно), role (operator/admin). Результат credentials={username,password,role}; показывается один раз в ответе, ответ не кешируется.

Шаблоны получают is_chief_operator, app_brand и public_url через общий context processor. Бот получает конфигурацию из django.conf.settings.BOT_CONFIG (dict, читает env). Файл .env.example дополняет root после интеграции.
