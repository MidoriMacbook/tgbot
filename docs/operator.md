# Инструкция оператора

1. Откройте http://127.0.0.1:8000/ и войдите с учётной записью, выданной администратором.
2. В ленте выберите статус, группу, исполнителя или диапазон дат создания. Даты включаются целиком по московскому времени. Сбросьте фильтры, если нужная заявка не видна.
3. Откройте номер заявки. Проверьте описание, контакт и категорию.
4. Для новой заявки нажмите «Взять в работу» или выберите активного сотрудника и назначьте ему заявку.
5. Для смены исполнителя у заявки в работе выберите другого сотрудника. В истории сохранятся прежний и новый исполнитель, автор и время действия.
6. Напишите содержательный результат, затем выберите выполнение или отклонение. Комментарий из пробелов не принимается. Закрытая заявка не открывается повторно.
7. Если появилось сообщение об изменении другим сотрудником, обновите карточку и проверьте историю. Не повторяйте действие вслепую.
8. После работы выйдите из учётной записи.

Все операторы работают с общей лентой. Статистика, справочники и управление сотрудниками доступны только администратору. Отключённый сотрудник не может войти, но сохраняется в истории старых заявок.

Статусы «В работе», «Выполнена», «Отклонена» ставят сообщение в очередь Telegram. Для доставки должен работать процесс `notify`. Проверяйте проблемы доставки через служебную команду и запись ошибок в БД; не обещайте доставку при недоступном Telegram API.
