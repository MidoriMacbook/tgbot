# Состояние

Ветка prototype. Текущая доработка: docs/plans/2026-11-05-hosting-dark-panel.md. Подготовлены домен pur3.me, узел c-pl-2.apexnodes.xyz и порт 10064. Удалённый контейнер и DNS не изменялись. Размещение описано в docs/hosting.md, итог — docs/hosting-release.md.

Панель тёмная и адаптивная: Lucide, shadcn, Anime.js, Motion for React, React/Bklit-графики реальной статистики. Готовые assets включены в проект; Node на хостинге не нужен. Внешний HTTPS нужен для Telegram Mini App; Cloudflare может обслуживать сертификат с HTTP origin на 10064.

Бот редактирует сообщения при inline-действиях, показывает постоянное цветное нижнее меню, использует HTML и Premium emoji с fallback. Настройки бота читаются из .env. Сохранены nonce подтверждения, безопасная HTML-разметка, совместимость старых черновиков и текстовых команд.

Итоговая серия: 71 тест OK, Django check, отсутствие новых миграций, pip check. TypeScript/Vite build успешен; JS 654 kB, gzip 215 kB, предупреждение о размере bundle. После запуска через run.py HTTP 200 у входа и panel.js; тёмная тема присутствует в HTML. Проверки не повторять без изменений или причины.

Пользователь запретил управление компьютером и лишние проверки на каждом этапе. CUA/браузерную автоматизацию не выполнять без нового разрешения. Визуальная проверка нового оформления и реальное открытие Mini App на домене не выполнялись.

Локально запущен скрытый run.py PID 14324, сайт http://127.0.0.1:8000. Локальные HOST/PORT и незащищённые cookies заданы только окружением процесса; .env содержит production-настройки. Логи logs/launcher.stdout.log и logs/launcher.stderr.log. Не запускать второй polling с тем же токеном. При переносе на хостинг остановить локальный launcher. Главный оператор admin; пароль — CHIEF_OPERATOR_PASSWORD в .env. /team/ позволяет ему создавать операторов и администраторов с однократным показом пароля.

Предыдущая живая приёмка до редизайна: docs/demo/telegram-live.json и docs/demo/scenario.md, задержки 2,944 и 3,344 с. Исходный замер производительности: docs/demo/performance.json. Архитектура Django/aiogram/SQLite, история и очередь сохранены.
